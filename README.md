Winza Store – Modern E-Commerce Web App

Winza Store is a responsive and modern e-commerce web application built to demonstrate real-world front-end development skills, clean UI design, and smooth user experience.

✨ Features

Dynamic product loading using API

Smart search, category filter, and price filtering system

Wishlist and cart management using local storage

Product preview modal and load-more pagination

Smooth animations, hero slider, and responsive layout

Clean, user-friendly, and modern interface

🛠️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

REST API Integration

Local Storage

🎯 Purpose of the Project

This project was created to practice real-world e-commerce functionality, improve front-end development skills, and build a portfolio-ready web application with modern UI/UX.

📱 Responsiveness

The website is fully responsive and works smoothly across:

Desktop

Tablet

Mobile devices
